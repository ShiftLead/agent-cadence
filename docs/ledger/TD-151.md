## TD-151: `precheck.py` runs only on a PR's head, so ShiftLead's promote cannot check main's head and `auto` never promotes a repo that gates on precheck

**Priority:** medium
**Type:** debt
**Added:** 2026-10-26 (Paul, through Add entry; drafted by session `ao-shiftlead-prompts`)
**Taken by:** ao-shiftlead-prompts
**Status:** Built 2026-10-26 (PR dev-cadence #374): `precheck.py --commit <sha>` (exclusive with `--pr`) fetches origin's default branch, refuses with exit 2 a commit not on it (or unknown), and otherwise runs the checkout's `precheck` in a clean detached worktree under `precheck-<sha7>-…/head` and records `cadence/precheck` on the commit; `--no-record` works with it; §4.12 says it; `tests/test_precheck.sh` 8–8e. **Location:** `files/scripts/precheck.py` (`--pr` is required; `main`); `tests/test_precheck.sh`; `files/docs/cadence.md` §4.12

**Why:** since TD-148, PRs gate on `cadence/precheck` and `ci.yml` runs only by hand, so a commit on `main` carries no check run. ShiftLead's promote waits for main's head to be green, so under `auto` it never promotes (`ao promote status` on 2026-10-26: *checks unknown (no check runs on 33f5df2)*), and every promote is pressed by hand. shiftlead#TD-1038 (design §6 *The precheck on main*) has the home run the precheck on main's head, and is built against a faked `--commit`. Its designer could not file this here (dev-cadence has no question seat), so it sat as an act line on shiftlead's board (2026-10-26, due 2026-10-29).

**Fix:** `precheck.py --commit <sha>` (exclusive with `--pr`) runs the repo's precheck on a commit of origin's default branch and records `cadence/precheck` on it, as `--pr` does on a PR's head:
- the same command from the checkout's `docs/cadence.toml`;
- the same clean detached worktree, context and exit codes;
- its temp directory named `precheck-<sha7>-…`, with the worktree `head` inside it, as `--pr`'s is;
- refused with exit 2 when the commit is not an ancestor of `origin/<default>`.
`--no-record` works with it, and §4.12 says it.

**Done when** a test runs `precheck.py --commit` on an ancestor of `origin/<default>` and records the status, and refuses one that is not (exit 2); and shiftlead#TD-1038's live run promotes on it.
