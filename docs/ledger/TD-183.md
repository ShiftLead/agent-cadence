## TD-183: `ledger.py --split` leaves the preamble describing the v1 layout, and flattens what sat under its `## Summary`

**Priority:** low
**Type:** debt
**Added:** 2026-10-28 (Paul, session `td-breakout`: seen in the ledgerboard and consumer-c splits, ShiftLead/ledgerboard#25, a consumer-c PR)
**Owner:** grinder
**Kind:** build
**Status:** Open
**Location:** `files/scripts/ledgerboard.py` `split()` (~1443, the `## summary` branch) and `_v2_readme()` — vendored, so the fix is a ShiftLead/ledgerboard release then a vendor PR; `files/scripts/ledger.py` `--split`

**Why:** the seed's preamble (`files/docs/technical_debt.md`) says "**This file holds open work only.** The summary table below lists exactly the entries…" and links `technical_debt_archive.md`, and `split()` carries it into `docs/ledger/README.md` unchanged. Every split repo's README then describes a table and an archive file it no longer has, and `--split` warns only about the archive link. Both 2026-10-28 consumer splits (ledgerboard, consumer-c) needed the paragraph rewritten by hand, and consumer-c's said resolved entries are deleted while its AGENTS.md said archived. Under the `## Summary` heading `split()` keeps only non-blank, non-table lines, so the seed's commented-out entry template, which sits there, loses its blank lines, and the `---` pair that framed the table is left as two separators with nothing between them. Each is cosmetic, but every repo that splits pays the same hand edit, and a missed one leaves a preamble that misdirects the next session.

**Fix:** in ledgerboard's `split()`, keep the `## Summary` section's non-table lines verbatim (blank lines included, an empty separator pair collapsed). In `ledger.py --split`, warn on a preamble line that names the summary table or the v1 files, pointing at the paragraph to rewrite. Optionally replace the seed's paragraph when it is still the seed's text unchanged. Tests: the seed itself through `--split`, expecting a README with no v1 wording and the template intact.

**Done when** splitting an unedited seed ledger gives a README that needs no hand edit, and an edited preamble that still names the v1 layout gets a warning.

**Related:** TD-160 (the split), TD-176 (archived: the link rewrite, the same kind of fix-up).
