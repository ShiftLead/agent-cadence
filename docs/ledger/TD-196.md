## TD-196: The board's stamps and entries publish the machine's host name

**Priority:** low
**Type:** debt

**Taken by:** b675de241e6c
**Location:** `files/docs/procedures/stranded-work.md` (the stamp step: `Swept: YYYY-MM-DD (<host>, quick|deep)`); cadence.md §3.10 (the stamp) and §3.3's board entry format (`session <id> on <host>`); `files/docs/procedures/memory-harvest.md` and `memory_harvest.py stamp` (`Harvested: YYYY-MM-DD (<host>, <n> repos)`, on the layer file); `nudge_user_attention.py` `SWEEP_RE`/`SWEEP_DEEP_RE`, which read the parenthesis as free `meta`

**Why:** the cadence writes `hostname -s` into committed text in three places: the sweep stamp, each board entry, and the layer's harvest stamp. In a public repo that publishes the machine's name. The step-4 privacy read missed one (`kmaster`, on this repo's board); a consumer that goes public has the same exposure, and nothing warns it. A host name is no credential, but it is a fingerprint, and a default host name often carries the person's name or the hardware (`<user>-<model>`). The board entry's host is load-bearing: it says which machine can resume the session (cadence.md §3.3's board format). The sweep stamp's host is not: the reader ignores it, and only a person reading the board learns from it which machine swept.

**Fix (to decide):**
- Let the repo name the host it publishes: a `host-label` key in `docs/cadence.toml` (§9.18), used in place of `hostname -s` where set, so a public repo writes `laptop` or `ci` instead of the machine's name.
- Or drop the host from the `Swept:` stamp only (no reader needs it), keeping it on board entries, where it is the point.
- Either way, the `cadence_layer.py --publish-check` idea extends to a repo: a check before going public that names host names, emails and session ids in the tracked tree and its history.
- Parity: the stamp's writer (stranded-work.md) and reader (`SWEEP_RE`) change together (cadence.md §7's table, `tests/test_parity.sh`).

Done when a repo can go public without its board naming the machine that swept it, by the repo's own setting or by default.
