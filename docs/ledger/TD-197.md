## TD-197: `ledger.py fmt`: an entry's canonical form, rendered from its parse, and written back

**Priority:** medium
**Type:** feature
**Added:** 2026-10-29 (Paul, session `sl-tds`: "the TD-173 design is right, file the builds")
**Owner:** grinder
**Kind:** build
**Status:** Open
**Taken by:** b675de241e6c
**Part of:** TD-173
**Location:** `files/scripts/ledger.py` (a new `fmt` command and the renderer the other commands share); `files/scripts/ledgerboard.py` (`entries()`, `header_block()`: the parse it renders from, read only); `files/docs/cadence.md` §2.12 (the field order it writes)

**Why:** every other TD-173 command, and the gate (TD-201), compare with or write "the helper's own rendering of an entry". That rendering is not defined anywhere today: ledgerboard parses an entry's header block but has no writer, and its SPEC names no canonical form. So it comes first. It also gives the person a way to keep editing by hand: edit, run `fmt`, push.

**Fix:**
- A renderer in `ledger.py`: an entry's parse goes in, its file text comes out. The heading comes first. Then the header block in one fixed field order: the cadence's fields in §2.12's order, then the repo's declared fields in their `Fields:` order, then any undeclared field in the order the file had it. One `**Name:** value` per line, then the sections (*Why*, *Fix*, *Done when*, others) with their prose as written.
- `ledger.py fmt [TD-n …]`, defaulting to every open entry, writes each entry back in that form. It changes no value, and leaves an `Id take` field (TD-188) exactly as found. `--check` prints the entries that would change and exits 1, writing nothing.
- The render lives in `ledger.py`, the one writer TD-173 names: ShiftLead calls the helper rather than rendering itself. If a second writer ever needs it, it moves to ledgerboard as a release.
- Tests: a round trip of every entry in this ledger and the archive changes no value; `fmt` is idempotent; an entry with an undeclared field keeps it.

**Done when** `ledger.py fmt` rewrites a hand-edited entry into canonical form without changing any value, and `fmt --check` on this repo's ledger reports what a first `fmt` would change.

**Related:** TD-173, TD-188, TD-070.
