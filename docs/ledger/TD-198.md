**Location:** `files/scripts/ledger.py` (`new`, over ledgerboard's `entry_text()`); `files/scripts/ledger_next_id.py` (the take it calls); cadence.md §2.10 (numbering) and §2.12; ShiftLead's `ao td reserve` (TD-182), which `new` absorbs

**Why:** filing is the write agents do most, and where the header conventions slip most: field order, `Taken by` copied by hand from the take's output, a wait written as prose. With `new`, filing an entry is one command, and the file is canonical by construction (ledgerboard's `entry_text()`).

**Fix:**
- `ledger.py new --title "…"` with a flag for every header field (`--priority`, `--type`, `--owner`, `--kind`, `--status`, `--blocked-by`, `--part-of`, `--location`, and `--field Name=value` for a repo's own fields). `--why`, `--fix` and `--done-when` each take a file, or `-` for stdin.
- The id comes from `ledger_next_id.py`'s take. Until TD-188's consumer side lands, `new` writes only the take's hashed `by` as `Taken by` (TD-195); after it, only `Id take`. `--id TD-n` files under an id already taken.
- It validates the result with `ledger.py --check --since`'s own flag set (`L.check` with the roster resolver and the rank file, `archive_loss_flags`, the id flags) plus `prose_wait_flags`, and refuses the write, naming the problem, on every error the gate counts. `cross-repo` is printed as a note, never a refusal. Two refusals of its own, about the entry it writes: a cross-repo id this command introduces whose roster repo was read and has the id in neither file (`Roster.state`'s `missing`, which `Roster.resolve()` drops today; the message carries `state()`'s `why` and says to fetch there), and a wait written in prose.
- An entry `canonical()` refuses is refused with the gate's hand-fix message.
- It writes `docs/ledger/TD-NNN.md` and prints the path. It commits nothing. A v1 ledger is refused with "split first".
- Tests: an entry from flags passes `ledger.py --check` and `fmt --check`; each refusal fires; stdin bodies work; two `new`s in a row take two ids.

**Done when** a session files a full entry with one `ledger.py new` command, and the file needs no hand edit to pass `--check` and `fmt --check`.
