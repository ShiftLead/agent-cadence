**Added:** 2026-10-29 (Paul, session `sl-tds`: "the TD-173 design is right, file the builds"; reshaped 2026-10-30 onto ledgerboard v2.2, plan `docs/plans/2026-10-29-ledger-writer-in-ledgerboard.md`)

**Location:** `files/scripts/ledger.py` (`set`, `note`, `edit`, over ledgerboard's `edit_entry()`); cadence.md §2.4, §2.12

**Why:** most entry edits after filing are one field (a `Blocked by` gaining an id, a Priority), a dated Status line, or a rewritten Fix. Done by hand, they are where TD-160's blocker ended up in a decision's pointer (TD-172) and where TD-151 and TD-154 waited in prose (TD-166). Checking each write as it is made stops those at the source, rather than in `--check` after the fact.

**Fix:**
- `ledger.py set TD-n --field value …` (the same flags as `new`; an empty value removes the field), `ledger.py note TD-n "…"` (a dated Status line), and `ledger.py edit TD-n --section <name> --from <file|->` (replaces one section, or adds it where SPEC says). Each calls `edit_entry()` with today's date.
- It validates the result with `ledger.py --check --since`'s own flag set (`L.check` with the roster resolver and the rank file, `archive_loss_flags`, the id flags) plus `prose_wait_flags`, and refuses the write, naming the problem, on every error the gate counts. `cross-repo` is printed as a note, never a refusal. Two refusals of its own, about the entry it writes: a cross-repo id this command introduces whose roster repo was read and has the id in neither file (`Roster.state`'s `missing`, which `Roster.resolve()` drops today; the message carries `state()`'s `why` and says to fetch there), and a wait written in prose.
- An entry `canonical()` refuses is refused with the gate's hand-fix message.
- Tests: one per refusal; `note` keeps earlier Status text; `edit` leaves the header and the other sections unchanged; `edit fix` on an entry with no Fix adds one.

**Done when** every routine edit of an open entry's header, Status or sections is one of these three commands, and each refuses the slips TD-166 and TD-172 record.

**Related:** TD-173, TD-166, TD-172.
