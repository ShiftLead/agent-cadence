**Why:** two board writes have no writer anywhere: a new `decide` item, with its kind, `Answers:`, `(default)` mark and detail block, and the archive of closed items. A session types those by hand. In agent-cadence nothing writes a new item at all: `board_edit.py` makes only snooze, done, decide and reply. ShiftLead's `board.py` adds plain and already-decided items through ledgerboard's `item_line()` and `decided_line()`, which take no kind or `Answers:`. Every hand-typed convention (one line per item, the field order, a `Due:` before the trailing fields, a reply's place) is one an agent can slip on. TD-173 settled this for the ledger: one rule, "never edit a ledger file; use `ledger.py`", with a gate that refuses an entry file the helper would not have written, leaves nothing to remember. The board needs the same, and Paul set the scope on 2026-10-30: every repo that uses ledgerboard writes its ledger and its board only through the helpers, never by hand.

**Ask:** Answered: Paul's go 2026-11-03, after design PR #72 merged; the grinder builds the converged design.
