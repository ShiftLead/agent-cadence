## TD-212: An interactive design holds its builds only in Paul's layer: make decision (<person>) on an in-conversation design the cadence rule for every user

**Priority:** Medium
**Type:** feature
**Added:** 2026-10-31 (Paul, session led-tds: "make sure this is generalized for other user names")
**Status:** Open
**Taken by:** 2e9dce7d0dea
**Location:** files/docs/cadence.md §2.4 and §4.8 (Design review rounds)

**Why:** The cadence already holds a design's builds once its review rounds end: §4.8's *Design review rounds* (TD-203) keeps the plan's entry `Blocked by: decision (<person>)` with an `**Ask:**` while its end-of-rounds item is open, and files no build unblocked. Nothing covers the time before that, while the design is still being shaped in an interactive conversation. Paul's personal layer fills that gap for him alone (layer §2.4 add, harvested 2026-10-26): an entry filed mid-conversation lands with `Blocked by: decision (Paul)`. Another user's interactive session files its design entries unblocked, so an unattended session can pick one while it is still changing. On 2026-10-31 (session `led-tds`, ledgerboard's target-design review) Paul decided that this decision gate replaces ShiftLead's temporary Hold, which is being removed in its own shiftlead entry, and he accepted the short window between adding a decision to an existing entry by PR and that PR's merge. The rule is general, so it belongs in `cadence.md`.

**Fix:** `files/docs/cadence.md` §2.4 states the rule for every user and points to §4.8's design-rounds paragraph for what follows: an entry that an interactive session files while its design is still in conversation, and every build filed from it, starts with `Blocked by: decision (<person>)`, where `<person>` is the human driving that session, never a hard-coded name. It carries an `**Ask:**` saying what releases it (for example "Go once the shape is final?"). The person's go lifts it: once ledgerboard#TD-010's decide lift lands, their Go on the entry's `decide` item; until then, a session runs `ledger.py set TD-n --blocked-by ""` on the person's word. The §4.8 paragraph then reads as the continuation of the same hold, not a second rule.

**Done when:** `files/docs/cadence.md` §2.4 states the rule with `<person>` and §4.8's design-rounds paragraph refers back to it. Paul's layer dropping its own copy is a later step in the layer repo, after this merges, and is not part of this entry.
