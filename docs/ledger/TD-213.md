## TD-213: Every reader of the single ledgerboard.py breaks when ledgerboard v2.3 ships it as a package, and the nudge would surface items the person hid

**Priority:** medium
**Type:** feature
**Added:** 2026-11-03
**Status:** Open 2026-11-03: Blocked by ledgerboard's v2.3 release (TD-021) rather than its last build (TD-019), which archives before the release is tagged
**Taken by:** 2e9dce7d0dea
**Blocked by:** ledgerboard#TD-021
**Location:** vendor_ledgerboard.sh; sync.sh (payload, RETIRED_FILES); launcher/words.py; files/scripts/board_edit.py, nudge_user_attention.py; docs/user_attention.md; files/docs/user_attention.md, technical_debt.md (seeds); files/docs/cadence.md §4.5; README; tests

**Why:** ledgerboard v2.3 (ledgerboard#TD-008, builds ledgerboard#TD-012 to TD-019) turns `ledgerboard.py` into a package, `ledgerboard/`, and ships the board writer `board.py` beside the module (ledgerboard's `docs/plans/target-design.md` §1.1). It also changes `snooze` to write `Hide until:` and leave `Due:` alone, adds a `due` action, and gives the module `needs_you(board, today)`, the one list of what needs the person (§6, §1.2). Every reader here of the single file breaks when the package lands, and the nudge would keep surfacing and escalating an item the person hid, unless the vendor PR changes them in the same PR (target design §7.2 step 0).

**Fix:** One PR that vendors the v2.3 package and makes this repo's v2.3 changes together (target design §7.2 step 0):
- **The package's readers:** `vendor_ledgerboard.sh`; `sync.sh`'s payload lists each package file on its own line, and `scripts/ledgerboard.py` joins `RETIRED_FILES` in the same sync; `launcher/words.py`; the README's file-class table; `tests/test_ledgerboard_fixtures.sh`, `tests/test_sync_provenance.sh`, `tests/test_cadence_hooks.sh`; and whatever else a grep for the literal `ledgerboard.py` finds.
- **`board_edit.py` becomes a wrapper** over ledgerboard's `board.py`, which brings `due`; it passes `--by` on every decide, never from git's `user.name`.
- **`nudge_user_attention.py`** surfaces, escalates and counts from `needs_you`, so hidden items are skipped everywhere it reads the board: the ranking (`overdue_days`, :249, :329), `surfaces_at_start` (:353-375) and the due counts (`n_due`, `total_due`, `worst`, :1646-1830).
- **This repo's board** `docs/user_attention.md`'s "To snooze: just edit the Due date" (:25) is reworded; the seeds `files/docs/user_attention.md:7` and `files/docs/technical_debt.md:7`, which name `scripts/ledgerboard.py`, name the package; a `cadence-changes.md` entry says so.
- **The `due` action's subject** joins the tool-made-edit subjects in cadence.md §4.5 (:99, :138), so the board-alone carve-out accepts it.
- **Every board** this repo seeds or holds gains its `People:` line.
- **The `Hide until` data check:** the PR shows no board here already holds a hand-written `Hide until:` (the one-time item-key exception, target design §6).

**Done when:** The v2.3 package is vendored, every reader of the old single file reads the package, `board_edit.py` wraps ledgerboard's `board.py`, the nudge reads `needs_you`, the boards carry `People:`, and the suite passes; ShiftLead's step-0 PR can then bump its pin to this release.
