## TD-226: set's reassign and override refuse when the person's board is another repo's: write the notices there by a tool PR

**Priority:** Low
**Type:** debt
**Added:** 2026-11-05
**Status:** Open
**Id take:** 6301bf5650704c6b8656368fdb7ebff6
**Part of:** TD-214
**Location:** files/scripts/ledger.py (_set_moved)

**Why:** `ledger.py set`'s reassign and override (TD-218) owe board notices — the new person's `decide` item and the old person's `fyi`, and closing the old person's items about the gate — on *the person's board* (ledgerboard's target design §3.2: this repo's own board if its `People:` lists them, else the roster board with the lowest `origin_key`). TD-218 writes them only when that board is this repo's own and refuses otherwise ("not written from here yet"), so a person whose board lives in another repo cannot be reassigned to, or overridden for, from this repo; and an item on another repo's board about the old gate stays open until that repo's gate sweep (TD-219) closes it.

**Fix:** Write the other repo's board half as a tool PR in that repo (target design §1.1 *What the consumer keeps*: "the tool PR in another repo, §6"), as the host's cross-repo decide does: a temp worktree at its origin/<default>, `board_edit.py add`/`done` there, a PR opened and squash-merged under the tool-edit subject. Until then the refusal stands.

**Done when:** A reassign to, and an override for, a person whose board is another roster repo's writes the notices there by a tool PR, with a fixture for each.
