## TD-229: The gate sweep skips items for another repo's board: open a PR in that repo, as set's notices do

**Priority:** Low
**Type:** debt
**Added:** 2026-11-05
**Status:** Open
**Id take:** 255fd8a73686412aa5af3a7877ca3247
**Part of:** TD-214
**Location:** files/scripts/gate_sweep.py (apply), files/scripts/ledger.py (_notices_pr)

**Why:** gate_sweep.py --apply writes only this repo's own board: the items sweep() files on another roster repo's board (a decision whose person's board is there, an event item for one of its entries) and its closes there are skipped and said, so a person whose board lives in another repo is never asked by the sweep, and a stale item there stays open until that repo sweeps.

**Fix:** Open a PR in that repo for its items and closes, as ledger.py set does since TD-226 (_notices_pr: a temporary worktree at its origin/<default>, the items' Context naming <this repo>#TD-n), left open for that repo's review (adds are no carve-out, cadence.md §4.5); idempotent like the sweep's own sweep PR (nothing while an earlier one is open on that repo).

**Done when:** gate_sweep.py --apply opens a PR in each other roster repo whose board gets items or closes, with fixtures for an item, a close, and an earlier PR still open.
