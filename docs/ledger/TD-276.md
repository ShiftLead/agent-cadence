## TD-276: The gate sweep's own board pull request fails the cadence check for naming the sweep's origin entry in its title

**Priority:** Low
**Type:** debt
**Added:** 2026-11-15
**Owner:** grinder
**Kind:** build
**Status:** Open
**Id take:** 3c6ef3ad86274cf79a978fb8606abe34

**Why:** The gate sweep's PR on this repo's own board is titled `board: gate sweep <date> — <n> filed, <m> closed (TD-219)` (`gate_sweep.py`, the `subject` in the own-board branch of `--apply`). The cadence check's `ledger` row reads every `TD-n` in a title as work the PR does, and fails when the PR touches neither of that entry's files, so every such sweep PR fails the cadence check out of the box: #224 (2026-11-15) did, and a session retitled it by hand so it could pass. TD-219 is archived; it is the tool's provenance, not the PR's work. A tool-written PR that fails the gate for its own title teaches its readers to retitle or ignore the row.

**Location:** files/scripts/gate_sweep.py (the own-board subject in --apply); files/scripts/check_cadence.py (the ledger row); tests/

**Fix:** Drop `(TD-219)` from the own-board subject in `gate_sweep.py` (the body already names TD-219 as the tool's origin), and update the tests that pin that subject (`tests/` — grep for `gate sweep` and `TD-219`). Check the other repo's board subject (TD-229's branch) and the lift PRs' subjects against the same row while there: a lift PR names the entry it touches, so it passes.

**Done when:** A gate sweep's own-board PR passes the cadence check's `ledger` row as written (NA: no TD named in the title), pinned by a test.
