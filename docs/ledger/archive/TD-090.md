## TD-090: Scrub the repo before it is made public: machine paths, private repo names, people and dated incident detail

**Priority:** Medium
**Added:** 2026-10-11 (shiftlead's anchor, on Paul's word)
**Owner:** grinder
**Kind:** build
**Status:** Resolved 2026-10-30 with TD-191: the repo is public, and the publish gate runs on every PR's precheck. **Cut over 2026-10-28** (Paul): this repo is the one canonical copy, seeded from dev-cadence at its last commit `C`, whose history is kept privately. The gate the scrub needed now runs on every PR: the precheck runs `cadence_layer.py --publish-check --accept docs/publish-accept.txt` over the tracked tree (`publish-gate = "required"`, TD-189). What is left is TD-191's last steps (publish, re-point, archive the private repo); this entry closes when TD-191 does.

**Why:** the history and the files carry what was only ever meant for this machine and these repos: `~/…` paths, the names and incidents of private consumer repos (the private consumer repos), session ids, dated incident write-ups, and the ledger and board text addressed to Paul. Making the repo public shows all of it, and the git history too, not only the tip.

**Fix (decided; the ADR's *Decision*):**
1. **The scrub gate.** `cadence_layer.py --publish-check` learns the short host name and a list of names to flag, read from the layer's machine settings and never written into the public tree. It exempts its own fixtures and the tool's own name. A test runs it over the snapshot's file set and fails on a hit.
2. **The wording**, in `files/`, `launcher/`, `tests/` and the README:
   - The exposing lines get placeholders (`consumer-a`, *a consumer*). Private repo URLs and the org name go, and the incident lessons keep their point without the name: `check_cadence.py` ~299, ~415 and ~1325; `forge.py` ~431; `list_sessions.py` ~25; `nudge_user_attention.py` ~18; `procedures/stranded-work.md` ~6; README ~3 and ~183; the comments in `tests/test_check_cadence.sh` (~216, ~251, ~392), `test_ledger.sh` (~197) and `test_briefs_primer.sh` (~11).
   - *Paul* becomes *the person*, and the machine's name becomes *the machine*. The `tests/ledgerboard/` fixture changes upstream in ShiftLead/ledgerboard, then is re-vendored.
   - A rule that is Paul's alone goes to his layer.
3. **The snapshot script.** It builds the public tree from the file set with no shared history, runs the gate, and adds a README note: *dev-cadence, published as agent-cadence*.
4. **Paul's part:** the ADR's `gh` steps, ending with the visibility switch.
