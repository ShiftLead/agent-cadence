**Location:** `files/scripts/ledger_next_id.py` (the default `--by`: the session id, else `git config user.email`); the counter branch `cadence/ledger-ids` (each take's `by:` line); the `**Taken by:**` field it tells an entry to copy (cadence.md §2.10); `ledger.py --check --since` and `check_cadence.py`'s `ledger` row, which compare an entry's `Taken by` with its take's `by`; ShiftLead's `agent_ids.py` `taken_by_line()` and `ao td next`, as a shiftlead entry

**Why:** by default every take writes the session's id into a commit message on `cadence/ledger-ids`, and tells the entry to copy it. In a public repo that publishes the id. The step-4 read found one: `0640017`, TD-193 and TD-194's take. An id is no credential: it names a transcript file on one machine, and `claude --resume` works only there. But it links every take and entry one session made, and it would match a transcript to the public record if one were ever shared. The fallback is worse: `git config user.email` publishes an address. A hash keeps all the gate needs: one session's takes still share a `by`, so `Taken by` still matches its take, and locally hashing an id again says whether a session made a take. A sha256 of a 122-bit random UUID cannot be turned back into the id.

**Fix:**
- The default `by` becomes the first 12 hex digits of the sha256 of the session id. With no session id, it is the hash of `user.email`, never the address itself.
- `--by` still takes a front end's own name verbatim.
- The judges compare as before, since both sides are the hashed value. A `by` that is a bare UUID or an address warns, naming this entry.
- cadence.md §2.10 says what `Taken by` holds, with a `cadence-changes.md` entry.
- TD-188's planned *Id take* field names the take's nonce, so it carries no id at all. If TD-188 lands first, this entry shrinks to the counter's `by:` line.
- The one published id, on `0640017`, is left as it is: amending the counter would mean a force-push while a team is taking ids.

Done when a take from a session, with no `--by`, writes a 12-digit hash on the counter and in the `Taken by` it prints.
