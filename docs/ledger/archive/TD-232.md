**Why:** A squash body written by the forge buries every `Agent-Model:` mid-body and names nobody as the merger, so git cannot trace a bad merge back to the session and model that made it (TD-177's Why). This is the composing half of TD-177's design (docs/plans/2026-10-31-merged-by-trailer.md, Designs 2 and 3), which Paul said Go to on 2026-11-05: a command that writes the squash subject and body ending in one trailer paragraph, while the merge itself stays a literal `gh pr merge` a merge guard still sees.
