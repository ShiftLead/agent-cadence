**Why:** §4.4 lets a service account push a board append straight to main, and the direct-commit audit passes it as **board-append**. A repo whose ruleset refuses direct pushes (§4.7) cannot use that route, so the append lands as a PR of its own. §4 gives that PR route to board edits (§4.5, TD-083) but has no PR form of §4.4. In `files/scripts/check_cadence.py`, `row_board_edit_pr` (~2475) returns None unless the title's `subject_kind` is `edit` or `archive`, so a tool's append PR goes to the ordinary review row. It fails `no cadence-review: comment` and, since TD-234, `--since` lists it as *merged outside step 5* rather than as a tool merge.

ShiftLead's `ao` writes its board appends this way. `src/sessionorc/board.py` `add` (*Put on the board*) and `add_decided` (the decided line a steer's or ask's answer writes) run ledgerboard's `plan_add` in the home's own tree, commit under ledgerboard's `append` subject, and land by `gh pr create` then `gh pr merge --squash`. shiftlead #2967 (merged 2026-11-05: title `shiftlead: append An entry that waits on … (session n/a)`, one commit, `docs/user_attention.md` +1 alone, a decided line) reads `FAIL review — no cadence-review: comment`. shiftlead's main took 12 such appends in the 7 days to 2026-11-05 (the asker's count). Every one is a false fail in the weekly sweep, and it buries the real bypasses that the merged-outside list exists to show.

The content is no looser than what §4.4 already passes unreviewed. Checked 2026-11-05: `classify_direct` run against shiftlead's squash of #2967 (4f98198df) returns `board-append`, so the decided line's form (`- [ ] decide … Due: … Decided: …`) already passes the direct audit's rules. Only the PR route lacks a carve-out. Asked for by shiftlead's TD-1412 design (ao's own merges are tool merges or go through step 5's line).

**Resolved:** 2026-11-06 (PR #151)

**Done when:** A tool's append PR in either form (a *Put on the board* line, or a decided line) passes the review row as `carve_out: board-append`, and `--since` lists it among the tool merges, each with a test. A PR outside those rules still takes review. cadence.md §4.4/§4.6 and cadence-changes.md record it.
