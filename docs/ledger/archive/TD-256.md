The `set by=` route (`files/scripts/ledger.py`, the lift in `set`, ~1440–1497) is this repo's wrapper over ledgerboard's board half: it calls `board.py`'s `plan_edit(board, "decide", …, board_only=True)` and, on success, prints the board path as written. ledgerboard's TD-067 plan (`docs/plans/TD-067-shared-part-lift.md`, *Consumers*) asks each consumer's vendor PR to check that a board half which writes nothing (`paths: []`, `subject: null`, exit 0, `left_open`) is taken as a success, the commit carrying the ledger alone under the `ledger: set TD-n …` subject, and that `left_open` is shown to whoever ran it.
