## TD-265: The ledger writer here cannot retitle an entry or remove a section, though ledgerboard's can

**Priority:** high
**Type:** debt
**Added:** 2026-11-14
**Status:** Resolved 2026-11-14
**Id take:** cd04b6d1a18b449690ea858fed2904f0

**Why:** ledgerboard v2.8 added two edits to its ledger writer: a retitle (`set TD-n --title T`) and section removal (`edit TD-n --section NAME --remove`). The plan for its TD-068 (*Consumers*) asked agent-cadence's vendor PR to check the wrapper's `set` for `--title`. The v2.8 vendor, TD-259's PR #199, did not. This repo's `files/scripts/ledger.py` lists `set`'s and `edit`'s flags by hand (`edit()` ~1219–1240). It has no `--title` for `set`, and `edit` refuses an empty section ("a section is never emptied by edit") with no `--remove`. So neither edit can be reached here, although the vendored module has had both since v2.8 (`files/scripts/ledgerboard/ledger.py:15`, `:24`; `plan_set(…, title=…)` ~538).

ShiftLead has no ledger wrapper of its own and runs this one, so the gap is in both repos. ShiftLead's grinder found it in the sync PR for ShiftLead TD-1803.

What it costs here, 2026-11-14:
- A retitle has no writer here, and cadence.md §2.12 lists removing a section among the hand edits that are left. TD-264 rule 7 needs a writer that retitles, and TD-264's own title has to be retitled.
- An answered `**Ask:**` cannot be removed, so TD-261's answered Ask had to be rewritten as "Answered: yes" instead of dropped.

Asked for by ShiftLead's grinder (ao-shiftlead-grinder-ao-2, by `ask`, 2026-11-14, m-1a30e0c9140b).

**Location:** files/scripts/ledger.py (edit() ~1219, the set and edit flags); files/scripts/ledgerboard/ledger.py (set --title, edit --remove; vendored v2.8); tests/; files/docs/cadence.md §2.12; files/docs/cadence-changes.md

**Resolved:** 2026-11-14

**Done when:** `ledger.py set TD-n --title "…"` retitles an open entry through ledgerboard's writer, and `ledger.py edit TD-n --section Ask --remove` removes that section. Both are tested, with the refusals. cadence-changes.md records them.
