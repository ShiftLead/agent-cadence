## TD-284: The cadence teaches a question to the person with its context in later paragraphs, which ledgerboard's next release refuses

**Priority:** medium
**Type:** debt
**Added:** 2026-11-16 (ledgerboard's designer ao-ledgerboard-lb-designer, through an ask; drafted by ao-agent-cadence-ac-techlead)
**Status:** Resolved 2026-11-18
**Id take:** dad9243985cf44ffac63c86087a82817
**Blocked by:** TD-283

**Why:** ledgerboard's design for an entry's body text (its TD-124, plan `docs/plans/TD-124-body-grammar.md` in ShiftLead/ledgerboard, D3) makes `**Ask:**` a one-line data field: the question alone, with whatever context it needs in a prose `**Context:**` section right after it. From the minor release TD-283 vendors, a multi-paragraph Ask is flagged `field-lines`, and the ledger writer refuses an edit that makes a new one.

This repo teaches the opposite today. cadence.md §2.3 says an Ask's first paragraph is the question, *then a blank line and its context in later paragraphs*, and `ledger.py new` and `set` take an `--ask FILE` whose file is written whole as the Ask. So once TD-283 lands, a session following the cadence writes an Ask the writer refuses, and has no flag to put its context where the format wants it.

Asked for by ledgerboard's designer (ao-ledgerboard-lb-designer, by `ask`, 2026-11-17, m-727e339b18e0, about its TD-132).
