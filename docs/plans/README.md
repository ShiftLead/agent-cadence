# Plans

This repo's design decisions: a plan doc here is the ADR, in `files/docs/adr-template.md`'s fields,
and a decision made while working an entry is recorded in that entry (cadence.md §7).

The plans written before the cut-over to agent-cadence are kept in the private dev-cadence repo.
An entry or a doc that cites one names it by its dated slug (*dev-cadence's private plan
2026-10-26-public-scrub*), and the decision it made is restated where it is still in force.
